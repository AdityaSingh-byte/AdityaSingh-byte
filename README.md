### duet

[![Two browsers and a real Android phone in one test: the phone approves the laptop's code. With the planted bug the wrong browser gets signed in and the test fails; with the fix it passes.](https://raw.githubusercontent.com/AdityaSingh-byte/duet/main/docs/media/demo-pairing.gif)](https://adityasingh-byte.github.io/duet/)

Lets an AI coding agent test a feature on a real Android phone and in visible browsers at the same time, while you watch: one step at a time, safe on someone's own phone, with the device log, a report and a video of every run.

`npm install -g duet-qa` · [site](https://adityasingh-byte.github.io/duet/) · [repo](https://github.com/AdityaSingh-byte/duet) · [npm](https://www.npmjs.com/package/duet-qa)

### agent-watch

[![The /watch console stepping through five Claude Code sessions: one waiting on you, two working, two idle](https://raw.githubusercontent.com/AdityaSingh-byte/agent-watch/main/docs/media/console.gif)](https://github.com/AdityaSingh-byte/agent-watch)

Shows every Claude Code session running on your machine from one console or browser page: which is working or waiting on you, what each changed, how its tests went, what it shipped, its tokens and its subagents. Press `r` for an AI review of a session, and `/route on` puts each delegated task on the cheapest model that can do it.

`/plugin install agent-watch --marketplace AdityaSingh-byte/agent-watch` · [repo](https://github.com/AdityaSingh-byte/agent-watch) · [release](https://github.com/AdityaSingh-byte/agent-watch/releases/latest)
